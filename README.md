Sitio estático en HTML y CSS, sin dependencias. Inglés en `index.html`, español en `es/index.html`.

## Publicarlo en GitHub Pages

1. En GitHub, crea un repositorio **público** llamado `TU-USUARIO.github.io` (con tu nombre de usuario exacto).
2. Sube el contenido de esta carpeta a la raíz del repositorio (botón *Add file → Upload files*; incluye el archivo oculto `.nojekyll`).
3. En el repositorio: *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, carpeta / (root)*.
4. En uno o dos minutos la web estará en `https://TU-USUARIO.github.io/`.

Si prefieres que el repositorio tenga otro nombre, la web quedará en `https://TU-USUARIO.github.io/NOMBRE/`; los enlaces son relativos y siguen funcionando.
